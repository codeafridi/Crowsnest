Your fleet, after the laptop closes.

The desktop app is yours, free and local. The relay is the other half: one place that holds the fleet view, the incident queue, the on-call rota and the alert delivery that keeps running while the machine that raised the alert is asleep. Every machine reports to it with its own token; the browser and the desktop read the same rows.

What the relay holds

The shared state a single machine cannot.

The fleet

Every machine that reports, with silence detection (suspect at 1.5 times the learned interval, silent at 90 seconds), duplicate detection and pre-registration. The desktop Team page shows the same rows the browser does.

Incidents that wait

Threshold and composite rules over stored rollups, dependency and flap suppression, folding, and acknowledge, close and silence with an audit trail. A DSM can acknowledge from the desktop or the browser; the server is the truth both read.

Delivery

Email, webhook (the Alertmanager v4 body with an HMAC), Slack, PagerDuty, Opsgenie, Discord and Teams, driven by a routing tree with group wait, repeat, escalation steps and an on-call rota. A retry ladder and a dead letter queue; every send is one ledger row.

Your data, on your terms

Retention is stated and enforced by one function. Export is streamed in the desktop client's own CSV dialect. Delete is a real delete with a counts receipt, and an optional export bundle whose sha256 is in that receipt.

The honest part

What the relay is not.

  • Not a licence check. The desktop app is fully free and never asks the relay for permission. Turning [remote] on is the whole upgrade.
  • Not metered local telemetry. The relay holds shared state. Your own machine's console stays local and unmetered either way.
  • Not collecting what you would not send. No process list, command lines, environment, paths or logs: the schema refuses them and the privacy page lists every field it does accept, generated from that schema.
  • Not hiding a gap. A silent machine shows a dash, a stale answer is dated, an unreachable relay is its own sentence, and the end-to-end proof is a committed transcript rather than a screenshot.

Start

Point one machine at it.

Install the desktop app, add the relay's address and the machine token, and the first report appears within one cadence. The rest of the fleet follows.

crowsnest.conf
[remote]
enabled = true
url = https://relay.example.com
token = the-machine-token

The token is minted in the relay's dashboard and shown once. [remote] actions additionally lets the desktop acknowledge, close and silence; reading is on with the link alone.
