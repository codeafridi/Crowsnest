01 / WHAT IT HOLDS

Fleet, incidents, delivery, rota.

One place the browser and the desktop Team page both read. The relay is the server side of shared state, not a second copy of the local console.

01

The fleet

Every machine that reports, with silence detection, duplicate detection and pre-registration. A silent machine is a dash in every value cell, never a stale reading.

02

Incidents that wait

Threshold and composite rules over stored rollups, dependency and flap suppression, folding, and acknowledge, close and silence with an audit trail. The server is the truth both the browser and the desktop read.

03

Delivery

Email, webhook (the Alertmanager v4 body with an HMAC), Slack, PagerDuty, Opsgenie, Discord and Teams, driven by a routing tree with escalation steps and an on-call rota. A retry ladder and a dead letter queue; every send is one ledger row.

04

Your data, on your terms

Retention is stated and enforced by one function. Export is streamed as the desktop client's own CSV dialect or JSON. Delete is a real delete with a counts receipt.

03 / SETUP

Four steps. The relay is yours.

Self-hosting is free and needs no managed service: one static binary, one Postgres database, and the free client on every machine you want to see. Managed hosting is not open yet.

  1. Install the client on each machine you want in the fleet. It is the same free app; [remote] is off until you switch it on.
  2. Run the relay on a server you control — one static binary and a Postgres database.
  3. Mint an ingest token in the relay's dashboard. It is shown once; each machine gets its own.
  4. Point the client at it with three config lines. An offline spool buffers what the machine gathered while the laptop was closed.
CROWSNEST CONFIG
[remote]
enabled = true
url     = https://relay.example.com
token   = the-machine-token

[remote] actions turns on the desktop verbs — acknowledge, close and a 30-minute silence from the Team page. Reading is on with the link alone, and a read-only token disables the verbs with the reason on the page.

04 / LIFECYCLE

Past due, cancel, delete.

These are the managed plan's clocks. A relay you run yourself has no billing, no trial timer and no expiry.

  • What is free: the desktop app and the relay. Self-host it with no licence key, no trial clock and no phone-home; every feature is in it.
  • Past due: 7 days of grace. Read-only by day 7, cancelled by the pass on day 8. Restore inside the window and everything keeps running.
  • Cancel: the plan runs to the end of the period, then data is kept 30 days before a real delete — counts in a receipt, and an optional export whose sha256 is in that receipt.
  • What you are not buying: gating of the desktop app. [remote] ships in the free build off by default, there is no licence check anywhere, and the report payload never carries process lists, command lines, environment, paths or logs — the schema refuses them and the field list documents every byte.
